원본 파일은 그대로 저장하고 CSS 표시 창으로 부품을 보여준다. 필터 구조 설명과 매뉴얼에서 가져온 11개는 `공식 구조도`로 표시하며 실제 판매 상품 사진과 구분한다. 웰스 토네이도 프리필터·올케어 필터는 단독 사진이 없어 해당 필터 이름이 표시된 전체 필터 구조를 사용한다. 긴 이미지도 WebP 최대 높이를 넘지 않도록 출력 크기를 제한한다.
