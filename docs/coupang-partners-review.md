   - 동작: 등록된 쿠팡 상품 페이지 또는 검색 결과를 새 창으로 열기
   - 표시: 제휴 링크 상태와 경제적 이해관계 문구를 버튼 가까이에 노출

## 데이터와 광고 분리 원칙

- 호환 관계는 제조사 공식 제품·지원·부품 자료를 우선해 등록합니다.
- 제휴 여부는 검색 순서, 검증 상태와 호환 판정에 영향을 주지 않습니다.
- 사용자는 구매 링크를 누르지 않아도 모델, 부품번호, 출처와 주의사항을 확인할 수 있습니다.
- 가격, 재고와 상품 이미지는 현재 API로 자동 수집하지 않습니다.
- 특정 판매자의 상품을 정품, 최저가 또는 100% 호환으로 보증하지 않습니다.

## API 승인 후 구현 원칙

- HMAC 서명과 API 호출은 브라우저가 아닌 서버 환경에서만 수행합니다.
- Access Key와 Secret Key는 서버 측 비밀 저장소에 보관합니다.
- 브라우저 번들, `PUBLIC_` 환경변수, Git 기록과 로그에 비밀값을 포함하지 않습니다.
- 상품 검색 결과는 부품번호와 모델번호를 기준으로 제한하고, 자동으로 호환 또는 정품 판정을 내리지
  않습니다.
- 가격·재고에는 조회 시각을 표시하고 만료된 응답은 다시 확인합니다.
