구매 카드 간소화, 판매 구성 표시, 잘못 연결된 구매 링크 대체, 쿠팡이 없는 부품의 국내 공식몰 연결과 해외 공식몰 안내를 반영했다. 원본 카탈로그는 Git에서 제외하며 정적 빌드에 반영한다.

## 의존성 보안 검사

호환 범위에서 의존성을 갱신했으며 Firestore Node 의존성의 고정된 gRPC 버전은 보안 패치 `@grpc/grpc-js@1.13.6`으로 지정했다. Firestore 규칙 테스트를 다시 통과했다.

`npm audit`에는 수정 버전이 없는 실제 라이브러리 2종과 해당 상위 의존성이 합산되어 high 7건이 남는다. 취약점 0건으로 처리하거나 CI 검사를 완화하지 않았다.

- [braces 재귀 처리 문제](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm): ESLint의 파일 패턴 처리 경로에 있으며 브라우저 앱에서 사용하지 않는다.
- [http-cache-semantics 공유 캐시 문제](https://github.com/advisories/GHSA-ch52-4w7c-c8xp): Astro의 Node 의존성이다. 현재 `output: static`과 Firebase Hosting의 `public: dist` 배포는 Node 서버나 npm 의존성 디렉터리를 제공하지 않는다.

현재 정적 Hosting 배포의 요청 처리 경로에는 이 두 라이브러리가 없다. 수정 버전이 발표되면 갱신해야 하며 SSR 전환 시 영향 판단을 다시 해야 한다. 현재의 엄격한 `npm audit --audit-level=high` CI 단계는 여전히 실패한다. 이번 배포는 검증한 로컬 정적 결과물을 Firebase CLI로 직접 올린다.
