# LG 360° 공통 필터와 액세서리

2026-10-10: [LG전자 2026년 1월 B2B 공식 카탈로그 131쪽](https://www.lge.co.kr/kr/ebook/2026/january/b2b/catImage/628/20260102_b2b_catalogue.pdf#page=131)의 적용 범위를 등록된 360° 모델 15개에 연결했다. 모델·부품 관계 49개를 추가했고, 기존 H/M5 필터와 AS205NGJA 판매자 호환 헤파형 상품은 유지했다.

| 품목          | 상품 코드 | 카탈로그 부품번호 | 적용 범위                |
| ------------- | --------- | ----------------- | ------------------------ |
| M 필터        | PFSALC01  | ADQ30041405       | 360° 공기청정기 전 모델  |
| G 필터        | PFSACC01  | ADQ30041403       | 360° 공기청정기 전 모델  |
| V 필터        | PFSAJC01  | ADQ30041401       | 360° 공기청정기 전 모델  |
| 극세필터 세트 | PFPNNC06  | ADQ75133511       | 360° 필터 전 모델, 6개입 |
| 무빙휠 1단용  | PWH8DBB   | AAA77724706       | 1단 모델                 |
| 무빙휠 2단용  | PWH8DBA   | AAA77724705       | 2단 모델                 |

이 관계들은 카탈로그의 시리즈 공통 적용 문구를 근거로 한다. 개별 모델에서 장착 시험을 했다는 의미는 아니다. V 필터는 기존 V2 항목과 부품번호가 동일해 중복 등록하지 않았다. 메인 필터는 M·G·V 중 선택하는 대체 구성으로 안내하며, 모두 동시에 필요한 것처럼 안내하지 않는다.

- 1단: AS153HWWC, AS183HWWA, AS186HWWA, AS205NGJA, AS205NSJA.
- 2단: AS283DWFA, AS285DWWC, AS303DWFA, AS305DWWA, AS305DWWL, AS336NSLC, AS355NGNA, AS355NSAH, AS355NSNA, AS356NSMA.

무빙휠은 `moving-wheel` 유형의 선택 액세서리로 구분하고 정기 교체 주기를 부여하지 않았다. 구매 링크는 확인된 LG 공식몰 상품으로 연결했다.

- [1단용 공식몰](https://www.lge.co.kr/care-accessories/360-air-purifier/cov31483702): 현재 PWH8DBB 판매 코드는 COV31483702이며, 카탈로그의 AAA77724706과 코드가 달라 상품 설명에 두 표기를 구분했다. 기존 AAA77724706 국내 페이지는 404로 확인되어 연결하지 않았다.
- [2단용 공식몰](https://www.lge.co.kr/care-accessories/360-air-purifier/aaa77724705).

모델별 교체 필요 수량과 판매처의 포장 수량은 구분한다. 극세필터 6개입은 판매 구성이고, M/G/V의 판매 수량은 확인되지 않아 제품 1대에 필요한 필터 수량으로 판매 구성을 추정하지 않았다.

상세페이지에서는 장착 위치를 기준으로 메인 필터·극세필터·이동용 무빙휠의 3개 유형으로 표시한다. 메인 필터 안에 해당 모델에 연결된 M/G/V, 기존 H/M5, 판매자 호환상품을 모은다. 상품별 부품번호·탈취 기능·구매 링크는 유지하며, AS205NGJA 전용 호환 헤파형 상품은 다른 모델로 확장하지 않는다. 원본 관계를 합치지 않고 화면에서만 그룹화하며, 기존 필터 해시 주소는 그룹 카드에 앵커로 유지한다.
