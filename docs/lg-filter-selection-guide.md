# LG 메인 필터 상품 선택 안내

상품 이름 아래에 탈취 성능 → 추천 환경 → 교체 주기를 표시한다.
이 정보는 각 상품에 적용하며, 같은 그룹의 다른 상품으로 확대하지 않는다.
모델별 호환 관계와 구매 링크는 변경하지 않는다.

## 자료

- 최신 M7/M5/V2/H 비교: https://www.lge.co.kr/care-accessories/360-air-purifier/adq30041401
- 해당 페이지의 전체 비교표: https://static.lge.co.kr/kr/images/care-accessories/360-air-purifier/md10779827/st_0415.jpg
- 기존 M/G/V 비교: https://www.lge.co.kr/support/solutions-20151419829672

자료 확인: 2026-10-11. 최신 표의 V2는 중, H는 약이다.
기존 M(ADQ30041405)/G(ADQ30041403)는 이전 공식 분류의 강/중으로 표시하며,
M5(ADQ30041414)의 MOF 소재나 V2 대비 배수를 기존 M에 적용하지 않는다.
추천 환경 문구는 소재와 탈취 성능을 바탕으로 간결하게 정리한 선택 안내이다.
약 1년은 제조사의 권장 교체 주기이며 실제 교체 시점은 환경과 상태에 따라 달라진다.

현재 등록된 M, G, V2, H, M5 및 AS205NGJA 호환 헤파형 두 상품에 적용한다.
M7은 현재 카탈로그에 등록되어 있지 않아 이번 표시 변경으로 추가하지 않는다.
호환 헤파형 두 상품은 확인된 탈취 기능 없음만 표시하고, 교체 주기를 추정하지 않는다.
