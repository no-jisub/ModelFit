# 외부 링크 재검증 기록

검증일: 2026-09-11 (Asia/Seoul)

## 범위

- 모델 공식 출처
- 소모품 공식·판매처 출처
- 정품·호환 상품 선택지의 출처
- 화면에 노출되는 공식·쿠팡 구매 링크
- 쿠팡 파트너스 직접 URL
- 카테고리 배너 링크와 이미지

감사 스크립트는 같은 URL을 중복 호출하지 않고, 각 URL을 사용하는 모델·소모품·상품 선택지를 함께 기록한다.

## 결과

`npm run audit:sources` 실행 결과:

- 참조 895개
- 고유 URL 137개
- 정상 응답 126개
- 자동 접근 차단 11개
- 실패 0개

기존 LG 2025년 하이마트 PDF는 연결이 끊겨 5개 모델의 공식 지원 페이지로 교체했다.

자동 접근 차단 11개는 쿠팡 상품 링크 9개와 카테고리 배너 링크 2개다. 쿠팡은 서버 요청에 HTTP 403을 반환하지만, 파트너스 단축 URL 4개와 배너 링크 2개는 쿠팡 도메인의 최종 상품·카테고리 URL로 리디렉션되는 것을 확인했다. 직접 상품 URL 가운데 검색 색인으로 상품명과 모델을 대조할 수 있는 링크는 유지했다. 가격·재고·판매자는 계속 수동 확인 대상으로 표시한다.

## 재실행

```powershell
npm run audit:sources
```

`failed`가 하나라도 있으면 명령이 실패한다. HTTP 401·403·429는 사이트의 자동 접근 차단 가능성이 있어 `blocked`로 분리하며, 상품 삭제 여부는 브라우저 또는 검색 색인에서 추가 확인한다.
