# 구매 링크 검토와 구매처 정책

2026-10-03 기준 전체 80개 모델을 1차 검토했다. 구매처는 쿠팡을 우선하고, 확인된 쿠팡 상품이 없으면 국내 공식몰의 직접 상품을 연결한다. 직접 상품을 찾지 못한 경우 공식몰 안내를 카드 앞에 표시한다. 해외 공식몰은 국내 배송 여부를 별도로 확인하도록 표시한다.

## 반영 내용

- 부품 카드에서 필요한 수량, 판매 구성, 구매 버튼을 먼저 보여 준다. 관리·근거·추가 설명은 상세 정보 하나로 접는다.
- 쿠팡 버튼 문구를 `쿠팡에서 구매하기`로 통일하고 기존 파트너스 고지를 유지한다.
- 상품 종류가 달랐던 X20+ 2개와 X10+ 3개 링크를 비활성화했다. 원본 행은 보존했다.
- 부품 종류와 적용 모델이 일치하는 쿠팡 대체 상품 5개를 추가했다. 검색에 저장된 판매자 자료를 대조했으며 현재 재고나 정품을 새로 보증하지 않는다. 새 링크는 일반 상품 링크로 수수료를 받지 않는다.
- 다이슨 필터와 에브리봇 Q11 필터·사이드 브러시·먼지봉투에 국내 공식몰 직접 상품 4개를 추가했다.
- LG 극세필터 6개입, Eufy X10 물걸레 6개와 먼지봉투 8개 묶음, 에브리봇 Q9 필터 옵션 선택 안내를 반영했다.
- 공식몰 안내는 `official-reference`를 유지하며 직접 구매 클릭 집계에서 제외한다.

## 데이터 보관과 검증

원본 CSV와 생성 데이터는 기존 정책에 따라 Git에서 제외한다. 카탈로그는 구매 링크 원본 158행 중 활성 153개, 상품 옵션 318개, 모델 80개다. 이번 추가 구매 링크 작업은 모델 호환 관계와 기존 근거 판정, 모델별 필요 수량을 변경하지 않았다.

수정 전 비공개 백업은 `private-backups/2026-10-03T11-05-19-904Z`, 수정 후는 `private-backups/2026-10-03T11-07-46-231Z`다. 셀 변경 증명과 상세 검토 자료는 Git에서 제외한 `outputs/`에 보관한다. CI용 압축 패키지도 갱신했다. 원격 Repository Secrets 갱신과 Git push는 이 로컬 커밋·직접 Hosting 배포에 포함하지 않는다.

## 남은 판매 자료 확인

쿠팡의 HTTP 403은 품절이나 상품 오류를 뜻하지 않는다. 상품 종류를 대조했더라도 현재 선택 옵션·판매 수량·재고·제조사 정품 여부는 판매 페이지에서 추가 확인해야 한다. 코웨이 모델별 적용 옵션, 나르왈 모델별 물걸레 적용 여부, 여러 부품이 공유하는 키트의 포함 부품을 우선 확인한다.

전체 외부 근거 링크 접근 감사는 고유 URL 297개 중 정상 177, 접근 제한 113, 실패 7이었다. 실패 7개는 기존 모델 설명·출시 근거이며 새로 추가한 국내 공식몰 상품 링크의 실패가 아니다. HTTP 404 5개와 통신 실패 2개는 후속 근거 정리 대상이다.
