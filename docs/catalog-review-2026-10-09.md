## 기본 필터와 교체 필터

관계 CSV `model-consumables.csv`에 선택 항목 `fitNote`를 추가했다. 모델별 안내가 다른 모델로 전파되지 않도록 부품 자체가 아닌 호환 관계에 보관한다. CSV 런타임과 SQL 준비 스키마·조회 필드를 함께 갱신했다.

- AS356NSMA: 기본 M7 → 공식 적용 모델에 포함된 M5 교체 필터.
- AS305DWWA, AS285DWWC, AS305DWWL, AS303DWFA, AS283DWFA: 기본 V → V2 교체 필터.
- AS186HWWA, AS153HWWC, AS183HWWA, AS336NSLC: 기본 장착 V2·H·M5 표기.

이 안내는 카드 앞면에 표시한다. 호환 가능 여부와 동일한 성능이라는 주장은 구분한다. 필요한 장착 수량과 판매 포장 수량은 기존처럼 별도로 표시한다.

## 정확한 옵션 가격 확대

기존 4개 구매 링크에 14개를 추가해 총 18개를 수집 대상으로 설정했다. 추가 대상은 다이슨 BP03·BP04 활성탄 필터, 블루에어 CP7i·3410 필터, 나르왈 Freo 먼지봉투, 쿠쿠 AC-14 및 AC-28AH 호환 필터, 샤오미 X20+ 먼지봉투·5 시리즈 메인 브러시, 웰스 토네이도 필터, 에브리봇 일회용 청소포, 유피 S1 Pro 브러시·먼지봉투 및 X10 Pro 물걸레다. 다이슨 두 부품은 같은 판매 옵션을 공유한다.

상품 ID·옵션 ID·판매자 ID가 모두 일치한 기존 상품만 선택하고, 세 ID가 포함된 주소를 파트너스 링크로 변환했다. 구성 종류가 불명확한 웰스 AL106 탈취필터 후보와 Saros Z70 물걸레 후보는 가격 대상에서 제외했다. 정확한 옵션을 확인하지 못한 나머지 링크도 추가하지 않았다.

로컬 수집 결과는 17/18개였다. 유피 S1 Pro 먼지봉투가 재수집에서 검색되지 않아 해당 가격을 숨겼다. 검색 결과와 가격은 변동하므로 이 숫자는 고정 보장이 아니다. 6시간 갱신, 24시간 표시 상한, 실패 시 가격 숨김 정책을 유지한다. 실패한 요청도 2초 간격 제한을 적용하도록 보완했다. API 원본 응답과 인증 키는 배포하지 않는다.
