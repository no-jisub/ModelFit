# 소모품 구매처·구성 정보 보완

2026-10-14에 구매처 조사, 공식 구성 보완, 미검증 재조사를 각각 나눠 진행했다. 검색 결과와 판매자 상품명만으로 공식 호환이나 정품 상태를 올리지 않는다.

## 1. 구매처

- Xiaomi X10+ 사이드 브러시는 대한민국 공식몰에서 실제 선택 옵션, 구매 버튼 및 국내 배송 안내를 확인했다.
- eufy C20은 롤러 브러시 1개, 사이드 브러시 6개, 먼지봉투 6개 옵션을, C28은 사이드 브러시 6개와 먼지봉투 12개 옵션을 확인했다. 판매자는 해당 모델 적용과 한국으로의 해외직구 배송을 표시한다. 제조사 정품이 아닌 판매자 주장 호환상품으로 등록했다.
- 코웨이 AP-2021A 펫 필터는 기존 품절 판매자를 유지하지 않고 다른 판매자의 상품을 별도 판매자 정품 주장 옵션으로 추가했다.
- 공유 코웨이 소모품에 연결된 AP-1521B용 상품은 AP-1521B에만 노출한다. 부품 종류의 공유를 판매 상품 전체의 모델 적용 근거로 사용하지 않는다.

- [코웨이 AP-1521B·AP-2021A 설명서](https://www.coway.com/core/product/fmanual/download/116): 4면형 프리필터 1세트, 4D 입체필터 내부 탈취 2개·집진 4개, 선택형 에어매칭 2개를 구분한다. 내부 탈취필터 2개를 입체필터 전체 2개로 표시하지 않는다.
- [코웨이 AP-3024H·AP-4025D 설명서](https://www.coway.com/core/product/fmanual/download/302): 상·하단 입체필터 2세트 및 에어매칭 총 4개를 구분한다.
- [Xiaomi 공식 액세서리 사양](https://www.mi.com/my/product/xiaomi-robot-vacuum-x10-plus-accessories/specs/): X20+ 적용 품번과 포장 수량을 확인했다. [본체 기본 구성](https://www.mi.com/global/product/xiaomi-robot-vacuum-x20-plus/specs/)의 사이드 브러시 1개와 판매 포장 2개는 별개다.

- 해외 공식몰에만 있는 iRobot 부품은 품번·포장 구성 참고 자료로 보완했다. 미국 재고 표시를 한국 배송 가능한 구매처로 등록하지 않는다.

## 3. 미검증 6건 재조사

- Dreame X40s Pro Ultra 5종: [공식 제품 가이드 검색](https://kr.dreametech.com/guide/manual?search_keyword=X40)에는 등록된 가이드가 없고, [공식 스토어 검색](https://store.kr.dreametech.com/search?q=X40s)에도 조회 시 결과가 없었다. 공식 제품 목록과 구매 링크의 모델명이 서로 다르며, X40 Ultra·L40s 상품을 대체 근거로 쓰지 않았다. 검색 결과 없음은 단종이나 판매 종료의 증거가 아니다.
- Coway AP-2021A 전체 호환 세트 1건: 기존 링크의 모델 불일치를 유지 기록했다. 다른 세트 후보 일부는 상세 조회가 제한됐고, 프리·집진·탈취 전체 구성과 정확한 적용 근거를 확인하지 못했다.

따라서 6건 모두 미검증을 유지한다. 미검증 수를 줄이기 위해 다른 모델 자료를 적용하거나 포장 수량을 장착 수량으로 추정하지 않는다.

새 구매처 중 쿠팡 API 검색에서 정확한 상품·옵션·판매자 ID를 대조한 5개는 기존 주기적 가격 갱신 대상에도 추가했다. 검색 결과가 달라지거나 ID가 일치하지 않으면 가격을 표시하지 않는다.
