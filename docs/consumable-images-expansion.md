# 소모품 참고 이미지 40개 추가

2026-10-09에 기존 20개에 40개를 추가해 총 60/180개 소모품에 이미지를 적용했다. 남은 120개는 이미지 미등록 상태다.

공식 상품·규격 페이지의 모델명과 부품번호를 대조하고 원본을 직접 검토했다. 본체가 함께 있는 쿠쿠 TMT20 사진, 에브리봇의 본사 직영 배지가 큰 사진 11개, 제목 문구가 큰 나르왈 사진은 제외했다. 에브리봇 Q11 사이드 브러시는 배지 없는 단품 사진을 사용한다. 샤오미는 홍보 페이지의 전체 세트 사진 대신 규격 페이지의 개별 부품 사진을 사용한다.

드리미 X40와 L10s Pro Ultra Heat의 메인 브러시·물걸레·먼지봉투는 공식 적용 모델이 함께 명시된 공용 부품 사진을 사용한다. X40와 L10s Pro Ultra Heat의 사이드 브러시는 서로 다른 부품 사진을 연결한다. 사진은 정품 모양을 확인하는 참고 자료이며 판매 상품의 실제 수량·정품 여부는 상품 행을 따른다.

브랜드별 추가 수: everybot 1개, irobot 6개, cuckoo 2개, roborock 4개, eufy 5개, dreame 9개, xiaomi 8개, ecovacs 4개, skmagic 1개.

원본은 프로젝트에 저장하고 기존 Astro 이미지 최적화와 모바일 배치를 사용한다. 외부 이미지 서버 상태나 쿠팡 API 호출에 의존하지 않는다. 출처와 확인일은 카드 상세 정보에 표시한다.

가로로 긴 브러시와 세로로 긴 필터가 잘리지 않도록 정사각형 썸네일 생성에 `fit="contain"`을 적용한다. 전체 이미지 로딩 검사의 제한 시간은 60개 대상으로 늘어난 실행량에 맞춰 90초로 조정한다.
