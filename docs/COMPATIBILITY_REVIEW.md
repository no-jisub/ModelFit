# 호환 근거 검토

2026-10-02 기준, 정규화 후 이어지는 1~3단계 작업을 수행했습니다.

1. 구매 링크가 있는 관계 192개와 여러 모델이 공유하는 부품의 관계 88개를 우선하는 검토 대기열을 작성했습니다. 두 범주는 겹칩니다. 전체 관계는 231개입니다.
2. 기존 공식 출처 125개 URL을 수집하고 공식 부품 상품의 적용 목록, 모델별 설명서와 구성표를 대조했습니다. 페이지 탐색 메뉴에 모델명이 있거나 출처 제목이 비슷하다는 이유로 확정하지 않았습니다. 접근하지 못한 자료는 확인된 자료로 간주하지 않았습니다.
3. 정확한 적용 범위를 확인한 관계 99개를 official/scoped로 전환하고 compatibility-sources.csv에 109개 출처 연결을 추가했습니다. 근거 부족·자료 충돌·모델군별 부품 식별 부족에 해당하는 132개는 unverified/legacy-unscoped로 조정했습니다. 미확인은 비호환 판정이 아닙니다.

LG는 카탈로그 PDF 131쪽의 부품번호·적용 제품군과 각 본체의 고객지원 제품명을 함께 연결했습니다. 아이로봇은 Combo와 일반 모델 및 도크를 구분했고, 에코백스는 T80과 T80S 적용 목록을 구분했습니다. 블루에어 DustMagnet 필터 페이지의 서로 다른 적용 목록은 충돌로 기록했습니다. 코웨이 공유 필터는 모델군별 구성은 확인했지만 같은 구매 부품이라는 증거가 부족하여 확정을 보류했습니다. 나르왈 Flow 먼지봉투는 도크 구분 확인이 필요합니다.

제조사 부품의 적용 근거는 판매자가 올린 호환 상품의 검증을 대신하지 않습니다. 상품 코드, 판매 구성과 관리 정보에 대한 기존 검토 항목도 별도로 남습니다. 검색 목록에는 모델별로 공식 확인 또는 호환 확인 필요를 표시하고, 모델 호환이 미확인인 상품 카드의 공식 자료 배지도 확정 표현을 사용하지 않습니다.

## 재검토와 적용

```powershell
npm run catalog:compatibility:review
npm run data:backup
npm run catalog:compatibility:review -- --from data/catalog/compatibility-review.json
npm run catalog:compatibility:review -- --from data/catalog/compatibility-review.json --apply
npm run catalog:update
```

기본 명령은 outputs/compatibility/review-queue.json에 대기열만 기록합니다. --from 명령도 --apply가 없으면 미리보기입니다. 검토 기록에는 compatibilityId, status, reviewedAt, sourceIds, note가 필요합니다. 출처별 페이지 위치와 판단 사유는 note에 직접 작성합니다. 공식 확정 시 활성 제조사 출처·브랜드 도메인·날짜·참조 무결성을 검사합니다. 이 검사는 출처 내용에 대한 사람의 판단을 대신하지 않습니다.

관계 ID와 구매 URL은 그대로 유지합니다. 공식 확인된 관계와 실제 확인한 출처의 날짜만 갱신했습니다. 미확인 관계의 기존 verifiedAt은 이전 자료의 역사적 날짜로 유지하며 이번 검토일은 검토 기록에 따로 저장합니다. 해당 날짜를 성공적인 호환 확인일로 표시하지 않습니다.

CSV와 검토 기록은 비공개이며 Git에 넣지 않습니다. 백업에 18개 CSV, 검토 기록과 생성 파일을 함께 보관합니다. CI 패키지는 판정과 출처 연결이 반영된 CSV 18개로 구성하며, 검토 기록 원문은 로컬 백업에 보관합니다. CSV 보완이 끝날 때까지 GitHub Secret 업로드는 보류합니다.

SQL 공식 컴파일·SDK 생성·에뮬레이터는 기존 Windows 실행 정책 문제로 여전히 검증 대기 중입니다. 이 작업으로 SQL 운영 전환을 완료했다고 간주하지 않습니다.

## 변경 보존 검사

검토 전 v2 백업과 판정 기록을 기준으로 다음 명령이 판정 외 변경을 검사합니다. 공식 확인 날짜와 관계별 근거 연결만 허용하고, ID·URL·판매 구성·관리 정보 등 다른 원본 변경을 거부합니다.

```powershell
npm run catalog:compatibility:check -- --before private-backups/2026-10-02T13-49-28-878Z
```

v1 정규화 보존 검사는 이전 출처 확인 날짜까지 동일해야 통과하는 역사적 비교입니다. 이번의 의도적인 출처 확인일 갱신 이후에는 위의 검토 보존 검사로 변경 범위를 확인합니다.
