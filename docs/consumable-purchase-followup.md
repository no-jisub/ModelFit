# 구매 구성·소모품 이미지·가격 후속 적용

2026-10-09 기준 확인 결과다. 카탈로그에는 공기청정기 50개와 로봇청소기 40개, 소모품 180개가 등록되어 있다.

## 구매 구성

- 웰스 AL106 탈취필터 후보는 H13 호환 필터 상품에서 탈취필터 단품 구성을 확인하지 못했다. 해당 판매 링크와 후보 옵션을 비활성화했다. 정품 규격 안내와 제조사 자료는 유지한다. 검색 누락을 판매 종료로 단정하지 않는다.
- Saros Z70은 퓨어퍼스트 타사 호환 물걸레 패드 6개 옵션을 선택했다. 동일 제품의 10개 옵션과 혼동하지 않도록 상품·옵션·판매자 ID를 지정한 파트너스 링크로 교체했다. 세트 상품이나 정품으로 표시하지 않는다.
- 샤오미 X10+·X20+ 물걸레는 퓨어퍼스트 타사 호환 10개 상품으로 판매 옵션을 분리했다. 공식 정품 안내는 구매처 없는 참고 옵션으로 남긴다.
- 블루에어 CP9i 판매 후보는 필터 1개 구성이다. 본체에 필요한 3개 장착 수량과 별도로 표시한다. 다이슨 HEPA 판매 옵션도 1개 구성으로 표시한다.

## 소모품 참고 사진

등록된 공식 자료와 개별 상품 페이지를 조사해 27개 이미지 원본을 확보하고 눈으로 검토했다. 본체가 크게 함께 나오는 위닉스 이미지 4개, 부품 식별이 어려운 여백·브랜드 표시가 있는 블루에어 이미지 2개, 홍보 표시가 많은 에브리봇 청소포 사진 1개는 제외했다. LG M·G 필터의 현재 공식 개별 페이지에서는 사용할 이미지를 확보하지 못했다.

1차로 20개 소모품에 공식 정품 참고 사진을 추가했다. LG V2·H·M5·극세필터 4종, 나르왈 5종, 에코백스 3종, 에브리봇 물걸레 2종, 유피 6종이다. 이후 공식 사진 40개를 더 검토·추가해 현재 총 60개에 적용했으며, 나머지 120개는 이미지 미등록 상태다. 추가 목록은 [소모품 이미지 확대 기록](consumable-images-expansion.md)에 정리했다. 다른 모델이나 액세서리 세트 사진을 개별 부품 사진으로 재사용하지 않는다.

이미지 원본은 프로젝트 자산에 저장하며, Astro가 240·480px WebP와 srcset을 생성한다. 브라우저는 작은 화면에 맞는 이미지를 선택하고 지연 로딩한다. 모바일에서 사진은 제목 옆에, 설명·부품번호는 전체 너비에 표시한다. 흰 이미지 바탕이 카드 배경과 자연스럽게 이어지도록 CSS를 적용한다.

사진에는 ‘정품 참고 이미지’를 표시한다. 사진에 보이는 개수를 타사 구매 상품의 판매 수량으로 해석하지 않도록, 상품 행에 별도의 실제 판매 구성을 표시한다. 출처 링크와 확인일은 상세 정보에서 확인할 수 있다.

정규화 구조를 유지하기 위해 `consumable-images.csv`를 별도 관계로 추가했다. 소모품별 1개 대표 이미지와 출처 FK를 갖는다. 경로·중복·활성 공식 출처를 검증하며 CSV는 총 19개다. CI 패키지와 SQL 준비 스키마·조회·시드도 동일한 계약을 사용한다. SQL 런타임 전환은 이번 작업에 포함하지 않는다.

## 가격 대상 확대

Saros Z70 물걸레, 다이슨 HEPA 필터, 샤오미 X10+·X20+ 물걸레, 블루에어 CP9i 필터를 추가해 가격 수집 대상은 18개에서 23개가 되었다. 유피 S1 Pro 먼지봉투는 검색어를 보완했다.

로컬 수집에서는 21/23개가 일치했다. 다이슨 HEPA 필터와 샤오미 X20+ 먼지봉투는 다음 수집에서 검색되지 않아 가격을 숨겼다. 검색 상위 10개와 가격은 매 요청마다 변할 수 있다. 상품·옵션·판매자 ID가 불일치하면 가격을 표시하지 않는다. 기존 6시간 갱신, 24시간 표시 상한, 실패 시 이전 가격 재사용 금지 정책을 유지한다.
