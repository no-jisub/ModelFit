# 소모품 참고 이미지 100개 확대

2026-10-09에 기존 60개에 공식 참고 이미지 40개를 추가했다. 전체 180개 중 100개에 적용했으며 나머지 80개는 미등록 상태다.

추가 수는 유피 13개, 에코백스 11개, 아이로봇 6개, 샤오미 6개, 나르왈 3개, SK매직 1개다. 공식 상품·규격 페이지의 적용 모델과 부품을 대조한 뒤 원본 사진을 직접 검토했다. 본체·홍보 문구가 함께 있는 위닉스와 블루에어 후보는 제외했다.

유피 S2와 C28의 필터·사이드 브러시는 각 모델의 서로 다른 공식 상품 사진을 사용한다. 에코백스 X11과 X12의 메인 브러시·필터·롤러 물걸레도 각각 구분했으며, 공식 공용 사이드 브러시만 같은 사진을 사용한다. 샤오미 X10+와 X20+ 먼지봉투는 공식 공용 규격 B101CNCHD 자료에 따른다.

사진은 정품 형태를 확인하는 참고 자료다. 사진에 보이는 개수는 판매 상품의 구성 수량을 의미하지 않으며, 구매 행의 실제 구성과 정품·호환 표시를 따른다. 구매 링크와 호환 판정은 변경하지 않았다.
