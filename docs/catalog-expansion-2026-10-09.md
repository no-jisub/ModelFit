# 상품 점검과 모델 확장 (2026-10-09)

## 대표 모델 5개

LG AS205NGJA, AS355NSNA, AS355NGNA, 위닉스 AZSE430-JWK, 쿠쿠 AC-17T20FWH를 점검했다. LG 2단 모델은 메인 필터 2개, AS205NGJA는 1개이며 LG 극세필터 판매 구성은 6개입이다. 위닉스 제로 S는 집진·탈취 필터를 구분하고 각 1개 필요 수량을 표시한다.

쿠팡 검색 API에서 M 필터, G 필터, 극세필터, 위닉스 호환 집진필터의 기존 상품 ID를 확인했다. 가격과 구매 대상이 달라지지 않도록 `itemId`와 `vendorItemId`까지 지정한 새 파트너스 링크로 갱신했다. 위닉스 상품은 판매자 호환 표기를 유지한다.

쿠쿠 필터와 위닉스 탈취필터는 검색 상위 10개에서 기존 상품을 찾지 못했다. 판매 종료로 판정하지 않았으며 가격은 표시하지 않는다. 확인되지 않은 판매 수량도 추정하지 않는다. 판매 패키지 수량과 제품 한 대에 필요한 수량을 구분한다.

## 신규 모델 10개

AS305DWWA, AS336NSLC, AS356NSMA, AS153HWWC, AS285DWWC, AS305DWWL, AS186HWWA, AS183HWWA, AS303DWFA, AS283DWFA를 추가했다. 이전 수요 조사에 포함된 모델과 같은 제품군 중 공식 자료에서 교체 부품을 검증할 수 있는 모델을 우선했다. 전체는 90개(공기청정기 50개·로봇청소기 40개)다.

모델별 공식 사양과 필터 판매 페이지의 **사용 가능한 모델 목록**을 대조했다. 제품 사진은 해당 모델의 LG 공식 갤러리 사진을 기존 720×720 WebP 규격으로 저장했다. 출시일은 확인되지 않은 경우 비워 둔다.

새 교체 필터 3종은 쿠팡 검색에서 부품번호·정품 표기 조건을 만족하는 상품을 확인하지 못해 공식몰 구매 링크를 제공한다. 검색 결과의 호환품을 정품으로 바꿔 등록하지 않는다.
